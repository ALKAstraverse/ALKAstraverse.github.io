Intro

Hi, I'm Huy Nguyen, a Web Developer who loves building fast, responsive websites that people actually enjoy using. I turn ideas into clean, modern web experiences — from landing pages to interactive apps — with a focus on detail, performance, and usability.

I'm always learning new tools and technologies to level up what I ship. I want to work on projects that make a real impact: improving user experience, solving tricky problems creatively, and building with modern web tech in collaborative teams.
